# OISM - Thư mục dự án

## 1. Giới thiệu

OISM (Omnichannel Inventory and Sales Management System) là hệ thống quản lý bán hàng và tồn kho đa kênh, hỗ trợ quản lý sản phẩm, đơn hàng, kho hàng và ứng dụng AI trong đề xuất nhập hàng.
