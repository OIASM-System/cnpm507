# 📊 Business Analysis (Phân tích nghiệp vụ) - POS PWA Project

Thư mục này tập trung lưu trữ toàn bộ các tài liệu phân tích nghiệp vụ (Business Analysis) dành riêng cho ứng dụng **POS PWA (Point of Sale Progressive Web App)**. Đây là nền tảng để chuyển hóa các nhu cầu thực tế của thu ngân và quản lý cửa hàng thành các đặc tả kỹ thuật chuẩn hóa cho đội ngũ phát triển.
