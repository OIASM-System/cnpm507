# 📚 Skills & Competency Management - POS PWA Project

Thư mục này quản lý toàn bộ tài liệu kỹ thuật, chuẩn phân tích, kiến trúc hệ thống, quy trình vận hành và năng lực đội ngũ cho dự án phát triển ứng dụng **POS PWA (Point of Sale Progressive Web App)**.

---

## 📂 Cấu trúc tổng quan thư mục `Skills/`

```text
Skills/

├── learning-roadmap.md                 # Lộ trình bổ sung kiến thức kỹ thuật trong quá trình làm đồ án
├── team-skill-assignment.md            # Phân công nhiệm vụ chi tiết dựa trên thế mạnh thành viên
│
├── 01-business-analysis/               # Phân tích nghiệp vụ bán hàng tại quầy (POS)

├── 03-backend-dotnet/                  # Kiến trúc & Lập trình Backend (.NET / C#)
├── 04-database/                        # Quản trị cơ sở dữ liệu, PostgreSQL & EF Core
├── 05-multi-tenancy-and-security/      # Đa thuê bao (Multi-tenancy) & Bảo mật hệ thống

├── 10-testing/                         # Kiểm thử phần mềm (Unit, Integration, Concurrency...)
├── 11-devops/                          # Quy trình quản lý mã nguồn, Docker & CI/CD
